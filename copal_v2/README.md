# Cebolletas Copal

Micrositio estático preparado para publicarse en:

https://cebolletas.mx/copal/

No requiere instalación, compilación, Node.js ni base de datos.

## Prueba local

Desde la carpeta del proyecto ejecutar: python3 -m http.server 8080

Después abrir http://localhost:8080.

## Publicación en GoDaddy

Copiar el contenido de esta carpeta a public_html/copal/

El archivo inicial debe quedar exactamente en public_html/copal/index.html.
No crear una carpeta adicional cebolletas-copal dentro de copal.
